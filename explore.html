Notes

  • $/tok/s = hardware cost ÷ single-stream tok/s; lower is better value
  • Cost is the low end of the quoted range; per-card prices for multi-GPU rows are not multiplied (original text shown)
  • Click any row for details, launch command and source; tick rows to compare them side by side
  • Metric shows an English version where one exists (hover for the original); hardware and other fields keep the source’s wording
  • Memory is read from the hardware text (e.g. “RTX 4090 24GB”, “2× DGX Spark”); rows that don't state it are left out when a memory filter is set. Only GPU / unified memory counts: system RAM used for offload is not included, and VRAM and unified memory are compared as equals unless you pick a hardware type
  • Discrete-card prices are usually the card alone; Mac, DGX Spark and mini-PC prices are the whole machine. Use “Price basis” to rank $/tok/s like-for-like
