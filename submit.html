配方库提交配方

提交一条配方

所有配方都以 PR 的方式进入仓库，经校验和人工审核后上线。

流程

  1. Fork 仓库，新建分支
  2. 在 data/recipes.json 追加一条（后续会拆成 recipes/*.yaml）
  3. 本地运行 node scripts/validate.mjs 通过校验
  4. 提交 PR，附原帖/日志链接；自测请附截图或完整命令输出
  5. 维护者核对来源等级后合并

YAML 模板

id: text-qwen38-27b-m4max-omlx
category: text            # text | image | video-audio
model: Qwen3.8-27B
quant: UD-Q4_K_XL         # 未知写 null
engine: oMLX 0.7          # 引擎 + 版本
hardware: Mac Studio M4 Max 128GB
hardware_family: Mac      # Mac | NVIDIA 消费级 | DGX Spark | AMD | 二手数据中心卡 | 其他
hardware_cost_usd: 3499   # 未知写 null，不要估
metric: "62 tok/s 生成；850 tok/s 读入（8K 提示）"
tok_s: 62
concurrency: "1 路"
context: 128K
launch_command: |
  omlx serve --model ... --ctx 131072
source_url: https://x.com/...
source_level: 实测        # 官方 | 实测 | 转述 | 宣称
date: 2026-10-13

规则

  • 不估算、不编造；拿不到的字段写 null，页面显示「未见公开数据」
  • 只存链接与摘要，不搬运 X 帖子全文
  • 来源等级：官方 = 项目方/厂商；实测 = 作者本人跑出；转述 = 二手引用；宣称 = 预测或未给出复现条件
